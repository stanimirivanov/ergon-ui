# Evidence model

## TL;DR

Own the documentary review model boundary for M06. Acceptance is human
documentary judgment, never operational truth or execution authority.

## Ownership

Platform-neutral proposal, citation and review values and rationale validation.
No React, Effect, DOM, transport, remote cache or permission policy.

## Verification

Use the root harness and focused Nx targets:

- `pnpm nx typecheck @ergon/evidence-model`
- `pnpm nx test @ergon/evidence-model`
- `pnpm nx lint @ergon/evidence-model`
