# Evidence feature-web

## TL;DR

Own the documentary review feature-web boundary for M06. Acceptance is human
documentary judgment, never operational truth or execution authority.

## Ownership

React owns queue/inspection presentation, RHF owns drafts, and local mounted state
owns immutable uncertain review intent. RTK owns remote data. Hide and unsubscribe
inspection before writes; uncertain recovery reuses the exact command, with no
automatic mutation retry. The host owns routes, session checks, scope retirement,
pagination and persistent-heading focus. Quotes remain inert plain text; no HTML,
remote links, source upload, contradictions or bundle publication.

## Verification

Use the root harness and focused Nx targets:

- `pnpm nx typecheck @ergon/evidence-feature-web`
- `pnpm nx test @ergon/evidence-feature-web`
- `pnpm nx lint @ergon/evidence-feature-web`
